Kali ini saya membawa kabar gembira untuk kita semua, terutama untuk teman - teman yang windowsnya masih 7 home premium. pada postingan saya kali ini akan diberikan tahap - tahap untuk upgrade windows teman - teman menjadi 7 ultimate. silahkan dibaca dulu sedikit penjelasannya.


Untuk apa mengupgrade windows ? silahkan lihat perbandingan windows 7 di sini.
Pada semua versi windows 7 yang diluncurkan, Windows 7 Ultimate merupakan sebuah penyempurnaan dari semua windows 7 versi sebelumnya atau bisa dibilang yang paling lengkap dari para pendahulunya. Dari hasil googling , saya menemukan cara upgrade windows 7 home premium menjadi ultimate .

Berikut adalah langkah - langkah yang harus dilakukan untuk meng-upgrade windows 7 home premium menjadi Windows 7 Ultimate.
*jangan lupa backup data anda dulu demi keamanan
  1. klik start (pojok kiri bawah)
  2. Pilih Control Panel, klik System and security setting dan klik windows anytime upgrade
  3. kemudian klik enter an upgrade key, masukkan kode ini 22TKD-F8XX6-YG69F-9M66D-PMJBM 
  4. kemudian klik next
  5. setelah itu, tunggu beberapa saat...
  6. windows anda telah berevolusi menjadi Windows 7 Ultimate
  7. Setelah di-upgrade, windows anda belum menjadi Genuine...
  8. untuk mengubahnya menjadi Genuine, silahkan download softwarenya klik disini
  9. klik 2x software tersebut
  10. kemudian klik install
  11. tunggu beberapa saat, lalu Windows 7 Ultimate anda is Genuine
  12. bisa dilihat di properties my computer (tekan logo windows + pause break pada keyboard untuk melihatnya)
  13. Windows anda telah terupdate menjadi ultimate
Segala bentuk kesalahan atau bugs yang terjadi diluar tanggung jawab saya, demi keamanan harap backup data anda terlebih dahulu dan jika ada pertanyaan silahkan langsung komen atau menuju sumbernya langsung.
