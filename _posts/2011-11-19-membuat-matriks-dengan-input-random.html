halo teman - teman . kali ini saya mencoba untuk sharing mengenai programming java. selagi saya bisa dan masih ingat jadi lebih baik berbagi untuk teman  - teman semua. kebetulan di kampus lagi heboh - hebohnya tugas mengenai programming java, sekarang saya sedang belajar array yang merupakan dasar dari pembentukan matriks. matriks dalam java merupakan array 2 dimensi karena memiliki baris dan kolom. 


kali ini kita akan belajar bagaimana caranya membuat matriks namun elemen - elemen matriksnya diinputkan secara random. coba kita lihat kode java di bawah ini.

import java.util.Random;                                             
public class matrix {
    public static void main (String [] args){
        Random rdm = new Random ();
        int nilaiRandom;
        int matrix [][] = new int [5][5];                          //ukuran matrix  
        //input matrix 
        System.out.println ("Matrix A\n");
        for (int i=0;i<5;i++){
            for (int j=0;j<5;j++){
                nilaiRandom = rdm.nextInt (5);                 //( ) masukan angka bebas
                matrix [i][j]=nilaiRandom;
                System.out.print (" "+matrix [i][j] );
            }
                System.out.println ();
        }
    }
}

coba kita run kode di atas, nah hasilnya akan terbentuk matriks 5 x 5 dengan elemen - elemen yang berubah - ubah setiap kali kita run. ini merupakan penggunaan perintah random yang terdapat dalam java. setelah kita bisa membuat matriksnya, cobalah untuk membuat koding java untuk penjumlahan, pengurangan, perkalian dan pembagian matriks :):)
