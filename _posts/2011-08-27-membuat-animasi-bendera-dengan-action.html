              Hi teman :) saya kembali mencoba berbagi. kali ini masih seputar dasar - dasar membuat animasi, namun sekarang lebih mudah karena menggunakan action di Photoshop. udah pada tau kan klo di photoshop ada yang namanya action. Ini gunanya adalah untuk mempermudah kita dalam mengerjakan sesuatu di photoshop dalam jumlah yang banyak, misal tukang cetak photo, pasti mereka menggunakan action ini agar lebih cepat.
jadi action itu adalah rekaman yang kita buat pada suatu foto misalnya, kemudian untuk mengedit foto selanjutnya kita tidak perlu lagi mengerjakannya manual, cukup gunakan action, maka foto selanjutnya pun akan teredit seperti foto yang pertama, jadi seperti itu gambarannya.

            kemarin kan sudah belajar bikin gerak / animasi di photoshop nah sekarang kita aplikasikan pada sebuah bendera seperti contoh di atas :D Baiklah, langsung saja disimak langkah - langkahnya ya :)


1. Download actionnya di sini Animflag.zip
2. Setelah file diextract, copy file animated flag.atn ke C; - program files - adobe - photoshop CS 3 - Presets - Action
3. Double klik file tersebut untuk menjalankan
4. Setelah Photoshop jalan, open file flaganimation.psd yang berada di folder animflag
5. Mulailah membuat bendera anda, pilih rectangle dan sesuaikan warnanya dengan selera teman" ingat ukurannya harus sesuai :) tambah gambar bila diinginkan
6. setelah bendera anda selesai, merge semua layer menjadi 1, dan beri nama "Flag"
7. Pilih windows - action - animated flag, dan kemudian klik tombol play
8. jika muncul sesuatu, pilih saja continue hingga bendera anda selesai dan terbentuk 13 layer
9. nah, sekarang kita tinggal menyusun satu persatu layer tersebut pada window - animation
10. masih seperti cara kemarin, tiap frame satu layer hingga layer ke 13, kemudian atur waktu jedanya sesuai keinginan teman"
11. kemudian save dengan menekan tombol keyboard "alt + ctrl + shift + S"
12. Save and Done !! :) 

Selamat mencoba :) :)
