kali ini saya mau sharing nih cara download file torrent namun tanpa menggunakan aplikasi downloader torrent seperti bittorrent dan sebagainya. cukup dengan downloader bawaan dari browser atau menggunakan IDM kita sebenarnya bisa mendownload file torrent. bagaimana caranya ? cekidot!!


1). Pertama kita cari dulu file torrent yang ingin kita download. contoh yang saya pakain yaitu untuk mendownload film di yify-torrents.com misalanya film "The Last Airbender". download file torrentnya ( sizenya kecil karena cuma file torrentnya saja ) seperti gambar di bawah ini



2). Kemudian buka torrage.com untuk men"cache" file torrent yang ingin kita download. klik choose file lalu klik "cache!"




3). Selanjutnya akan muncul tampilan sebagai berikut ini


4). Copy linknya kemudian buka zbigz.com dan paste link tadi pada text field kemudian klik "GO", pilih "FREE"



5). Nahh, sekarang kita tinggal menunggu beberapa detik agar file torrent yang kita download berbentuk .zip atau .rar


6). Jika sudah selesai, klik tombol .ZIP maka file akan siap didownload seperti gambar berikut ini, selamat mencoba =)
