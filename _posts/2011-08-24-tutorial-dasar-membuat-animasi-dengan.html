          Halo teman - teman :) mau share nih cara bikin animasi di photoshop. sebelumnya udah pada tau belum kalo di photoshop ( CS 3 ) bisa bikin animasi lho, format .gif. nih langsung aja simak dasar - dasar bikin animasi di photoshop. ingat !! DASAR lho, jadi sederhana banget :) CEKIDOT !!
* klik gambar untuk memperbesar. ..

1. Tentunya buka photoshop CS 3 dulu donk :D 



    2. Kemudian klik file - new, hingga muncul seperti gambar di bawah ini . atur deh ukurannya, biar agak besar contohnya saya pake 500 x 500 ya. ..

      3. Untuk contoh sederhana, kita coba bikin tulisan aja dulu . nanti lanjut level selanjutnya :) klik icon seperti gambar di bawah, dan tuliskan apa yang teman inginkan
        4. Setelah ada layer, duplicat layer tersebut sebanyak 2 kali hingga akhirnya terdapat 3 layer yang sama
          5. Klik layer ke-2 seperti gambar di bawah, pilih filter - blur - motion blur

            6. Kemudian atur tingkat bluringnya terserah teman - teman, pastikan layer ke-2 tingkat blurnya tidak melebihi layer 3

              7. Lakukan hal yang sama pada layer ke-3 dengan tingkat bluring > dari layer 2
                8. Setelah kedua layer di blur, sekarang pilih window animation
                  9. Kemudian akan muncul seperti gambar di bawah ini, klik duplicate selected frame untuk menggandakan dan ganti layernya dengan layer 2 yang sudah kita blur tadi *lihat gambar

                    10. Lakukan hal yang sama pada frame yang ketiga
                    11. Untuk frame ke-4 layernya dikosongkan saja untuk memberikan efek menghilang pada animasi kita nanti 12. Atur waktu jeda tiap - tiap frame *lihat gambar
                      13. Klik tombol play untuk melihat hasil gerakannya
                      14. Sekarang kita save animasi yang sudah jadi , klik file - save for web and device
                        15. Atur sedikit jumlah warna, dither, dll kemudian klik save
                          16. File yang kita save akan berformat .gif dan siap untuk digunakan sesuai keperluan :)


                                        gampang kan teman ? :) ya itu baru dasar atau pengenalan saja untuk teman - teman bahwa di Photoshop tidak hanya untuk mengedit foto tapi jga dapat digunakan untuk membuat animasi yan gmenarik . tunggu level selanjutnya ya, tentunya akan ada tutorial yang lebih asik lagi untuk kita pelajari . tetap semangat kawan :) :)
